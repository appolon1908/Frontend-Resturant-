# Frontend (Nuxt 3)

## Setup

```bash
npm install
```

## Environment

Copy and edit env values:

```bash
cp .env.example .env
```

Required:

- `NUXT_PUBLIC_API_BASE_URL` - backend API base URL (example: `https://your-api-domain.com/api/v1`)

## Run

```bash
npm run dev
```

## Typecheck

```bash
npm run typecheck
```

## Build

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
